# SystemMonitor

A Windows-style Task Manager for Android tablets and phones: processes per app, live graphs for CPU, memory, storage, network and GPU, a Clean button for cached apps, and a setup guide. No root (uses Shizuku); the internet is only used for in-app update checks and downloads from this repo.

- Website and setup guide: https://overnightcoder219.github.io/systemmonitor-app/
- Download: [Releases](../../releases/latest). Each release has the APK and its SHA-256.

This repository holds only the download website and the signed releases. SystemMonitor is a personal project, not affiliated with Shizuku/RikkaApps, Xiaomi, Microsoft or Google. © 2026 OverNightCoder.
